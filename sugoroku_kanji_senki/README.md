# すごろく漢字戦記 v17

## v17 調整
- 「一心不乱」の説明を実装に合わせて「次のおみくじで7字から2字獲得」に修正
- 「五里霧中」は手札を隠さず、「次の1ターン、熟語進捗が霧に隠れ熟語札を作れない」に統一
- CPUの漢字価値判定から、すでに完成済みの熟語を除外
- CPUが複数の熟語を同時に完成できる場合、能力価値と現在状況を見て作成する札を選択
- 3枚目の熟語を完成できる場合は勝利を最優先

## 現行ルール
- 初期手札：5字
- 本陣：3字から2字獲得
- おみくじ：5字から2字獲得
- 一心不乱：次のおみくじは7字から2字獲得
- 市場：2字から1字無料獲得、または2字を支払い5字から1字選択
- 城：最大3文字、文字数ぶん徴収
- 四字熟語札3枚完成、または他勢力全滅で勝利
- 熟語完成時に読み・意味・能力を表示
- SE・BGMあり

## v22 ローカル1～4人対戦
- ゲーム開始時に人間プレイヤー数を1～4人から選択
- 残りの勢力はCPUが担当
- 1人：紅＝人間、蒼・翠・紫＝CPU
- 2人：紅・蒼＝人間、翠・紫＝CPU
- 3人：紅・蒼・翠＝人間、紫＝CPU
- 4人：4勢力すべて人間
- 1台のスマホ／PCを手番ごとに使い回すローカル対戦
- 手番が移ると主表示もそのプレイヤーへ自動切替
- 上部4勢力パネルを押すと、他プレイヤーの手札・熟語進捗・城数をいつでも確認可能
- 本陣・おみくじ・市場・築城・城強化・熟語能力の選択は、その手番が人間なら本人が操作
- CPU席だけ自動処理
- BGMは人数選択後のゲーム開始時に再生


## v23 熟語進捗ポップアップ
- 盤面中央に「📜 熟語進捗」ボタンを追加
- スクロールせず、現在手番プレイヤーの5熟語の進捗をポップアップ表示
- 各熟語を4文字単位で表示
  - 所持している文字：強調表示
  - 不足文字：薄色表示
  - 完成可能／獲得済みも表示
- 本陣・おみくじ・市場など漢字獲得時に進捗を同時表示
- 市場交換で捨てる漢字を選ぶ際にも進捗を表示
- 築城・城強化で使用漢字を選ぶ際にも進捗を表示
- 一部の熟語能力による漢字選択時にも進捗を表示
- 敵城の徴収で失う漢字を選ぶ際にも進捗を表示
