# すごろく漢字戦記 v17

## v17 調整
- 「一心不乱」の説明を実装に合わせて「次のおみくじで7字から2字獲得」に修正
- 「五里霧中」は手札を隠さず、「次の1ターン、熟語進捗が霧に隠れ熟語札を作れない」に統一
- CPUの漢字価値判定から、すでに完成済みの熟語を除外
- CPUが複数の熟語を同時に完成できる場合、能力価値と現在状況を見て作成する札を選択
- 3枚目の熟語を完成できる場合は勝利を最優先

## 現行ルール
- 初期手札：5字
- 本陣：3字から2字獲得
- おみくじ：5字から2字獲得
- 一心不乱：次のおみくじは7字から2字獲得
- 市場：2字から1字無料獲得、または2字を支払い5字から1字選択
- 城：最大3文字、文字数ぶん徴収
- 四字熟語札3枚完成、または他勢力全滅で勝利
- 熟語完成時に読み・意味・能力を表示
- SE・BGMあり
