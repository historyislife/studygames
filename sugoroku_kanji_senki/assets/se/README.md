# SE assets

These WAV files are procedurally synthesized specifically for this game package.
No third-party sound recording is included in this folder.

Mapping:
- se_dice_roll.wav — dice rolling
- se_dice_land.wav — dice landing
- se_piece_step.wav — one board-space movement
- se_castle_build.wav — castle construction
- se_omikuji.wav — omikuji / shrine bell
- se_kanji_get.wav — kanji acquired
- se_kanji_steal.wav — kanji collected/stolen
- se_idiom_complete.wav — four-character idiom completed
- se_skill_activate.wav — ability activation
- se_player_eliminated.wav — player eliminated
- se_victory.wav — victory fanfare

The game refers to these files through the `SE` object near the top of `index.html`, so they can be replaced later without changing game logic.
