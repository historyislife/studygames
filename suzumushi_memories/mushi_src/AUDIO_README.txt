鳴き声音源について
==================

このゲームに収録した10種類の鳴き声は、実際の録音をコピー・切り出したものではありません。
各種で一般的に知られる鳴き方（音の高さ、長さ、繰り返し、擬音表現）を参考に、
正弦波・倍音・周波数変調・振幅変調・ノイズ等を組み合わせて新規に合成した学習用音声です。

そのため、野外で聞こえる実際の鳴き声とは、個体差・気温・距離・鳴き方の種類などにより異なります。
「実録音」ではなく、種類ごとの特徴を聞き分けるための補助教材として使用してください。

収録種:
スズムシ / マツムシ / エンマコオロギ / カネタタキ / カンタン /
アオマツムシ / クツワムシ / ハヤシノウマオイ / ニシキリギリス / ツユムシ
